# 视频转速与升挡提醒

2026-10-30，光效增强版。本主题用于在 ICarUI 中制作、预览和继续编辑视频参考风格的圆形转速仪表。

本次更新新增正式的“粒子火花”和“扩散波纹”特效选项：金色火花带短尾迹向外飞散并熄灭，三道波纹先后扩散后消失。参数随主题保存，可在编辑器中继续修改。请使用本次更新后的 ICarUI；旧版编辑器和旧版 APP 不支持这两种新特效；Android 已在本次 1.21.5（97）Debug 测试包中完成适配。

## 直接看动态效果

双击本目录的 [演示.html](演示.html)。可离线打开，无需启动服务。

- 自动循环 18 秒：转速拉升、5400 转升挡提醒、模拟换挡回落、再次拉升、减速。
- 拖动转速滑块后固定读数，提醒光效继续运行；可暂停光效。
- “正常行驶”“升挡提醒”可快速比较两个状态；“模拟换挡”播放转速回落。
- “开启提醒光效”只控制提醒部分，保留正常灯带发光。
- “粒子火花”和“扩散波纹”可以分别开关，比较各层效果；这些演示开关不改动可下载主题。
- “重新播放”恢复自动循环。页面隐藏时暂停；系统偏好减少动态效果时，初次打开保持暂停。

`转速与升挡_动态预览.mp4` 是通过同一套 ICarUI 绘制器逐帧生成的 18 秒、640×640、30 fps 预览。它不是设备性能录屏。

本次另提供同内容的明确版本文件：`转速与升挡_粒子波纹增强版.mp4`、`升挡效果_粒子波纹增强版.gif`、`视频转速_粒子波纹增强版.icarzip`。原有文件名同步更新，项目主题库继续使用原路径。

## 在 ICarUI 中使用

打开本次更新后的 ICarUI，选择“主题 → 项目主题”，搜索“视频转速”，打开“视频转速 · 粒子火花与扩散波纹”。可选择动态预览场景，再应用到画布。已有编辑器需要刷新才能读取新特效和索引，刷新前请先保存手头设计。

也可使用“我的收藏 → 导入主题”，选择 `视频转速_720x720.icarzip`。它包含 `design.json`、4 张 PNG 和 `manifest.json`，不依赖本演示网页。

主题采用 `icar.ui/3`，设计尺寸为 720×720，等比显示。最外层为一个组合，可作为整个控件移动、缩放和保存。图层包括：黑色底板、提醒底光、暗轨与刻度、64 段转速灯带、旋转高光端点、两道提醒圆环、三重扩散波纹、金色火花、ENGINE/SHIFT 状态、主转速、车速、挡位和进气温度。

## 在 Android 测试版中使用

安装 [最新 ICarOBD 测试版](https://github.com/misakashiny/iCarOBD/releases/latest)，在「主题与画布 → 导入主题」选择本目录原有的 `.icarzip`，确认导入后进入画布。包内四张 PNG 和全部新光效参数一起导入，不需要另选素材目录或转换文件。旧版 APP 需要更新。

无车看效果：在「连接 → 模拟信号」点击「满量程快扫」，再点「开始模拟」，返回导入后的画布。5400 转以上出现提醒、火花和波纹，转速回落后退出。关闭时回到模拟信号页点「停止模拟」。`obd.gear` 没有内置模拟通道时，挡位显示 `--`，需绑定可用的真实或自定义来源。

需要修改效果时回到 ICarUI 调整参数，重新导出同一格式后导入 APP。Android 使用原生实时绘制，粒子位置、寿命、扩散和触发规则按相同参数计算；字体、抗锯齿和屏幕发光不保证逐像素相同。

本地完成 JVM 2188/0、168 帧跨端几何对齐、API33 新光效检查 53/0 及原套件 226/0；包含正式画布接入内置模拟源。没有安装用户手机或做实车验收。历史原始验收资料仍保留在原工作区，本次未重新进行 Android 或实车验收。

## 修改火花与波纹

在图层中找到“5400 转 · 金色火花与短尾迹”或“5400 转 · 向外扩散的三重波纹”，进入编辑控件的特效设置；也可直接使用右侧“特效”属性。输入 5700 作为测试值即可试播。

| 可编辑参数 | 含义 |
|---|---|
| 触发数据、阈值、持续满足、退出回差 | 决定何时开始和结束，沿用已有规则语义 |
| 动画周期、相位、单次寿命 | 控制整轮重复节奏和每次飞散/扩散的持续时间 |
| 起始半径、结束半径 | 相对于特效图层圆形范围的 0～1 比例 |
| 粒子数量、大小、尾迹长度 | 改变火花密度和形状；最多 96 个/规则 |
| 粒子分布种子 | 固定值产生可复现的分布，换值可调整位置 |
| 波纹数量、线宽 | 控制依次扩散的光环，最多 6 道/规则 |
| 光色、强度 | 改变色调和亮度 |

两种特效分别占一个普通形状图层，形状本体透明；移动、缩放、隐藏、组合和调整透明度仍使用原有编辑方式。火花和波纹由 ICarUI 根据保存的特效参数实时生成，4 张 PNG 仍只负责原有刻度、高光点和状态标签。

## 数据与提醒设置

| 内容 | 绑定 | 第一版设置 |
|---|---|---|
| 转速、灯带、光点 | `obd.rpm` | 0～6500 RPM |
| 升挡状态、红色底光、亮环 | `obd.rpm` | 大于等于 5400 RPM |
| 主数字颜色 | `obd.rpm` | 5400 转变橙色，6200 转变红色 |
| 车速 | `obd.speed` | 演示值随场景变化 |
| 挡位 | `obd.gear` | 模拟来源；实际使用需要绑定真实可用来源 |
| 进气温度 | `obd.intake` | 演示为 33～36 ℃ |

5400 RPM 仅为复刻视觉时使用的示例阈值。修改提醒点时，应同时调整“ENGINE/SHIFT”图片的状态阈值、各提醒图层的特效阈值及主转速的颜色阈值。演示页面的 18 秒数据脚本和模拟值不会写入导出的主题。

## 实现与复现

`demo.js` 只负责界面操作和写入 `CanvasState.previewValues`。仪表使用项目现有 `canvas.js` 的 `drawNodePreview()` 绘制，没有独立手绘的替代仪表。PNG 均由 `make-theme.js` 中的几何绘图生成，未使用原视频截屏作为仪表皮肤。

`theme-data.js` 是可供项目主题库读取的纯数据。`make-theme.js` 是素材和主题的生成源；本轮生成、封包及验证脚本保存在项目的 `_本地优化验证/20261030-video-rpm-v2/`，第一版记录保留在 `20261030-video-rpm/`。维护生成源后，先重建主题包与预览，再运行 `node themes/build-catalog.cjs` 更新索引。

电脑端阶段已验证浏览器播放、导入、参数编辑、再导出与编辑器预览；Android 接续已生成 1.21.5（97）测试 APK 并完成上述本地验证，未做实体设备或车辆验收。本包的新光效需要本次更新后的 ICarUI 和已适配的 Android 测试版。扩散和粒子是按参考视频重建的实时效果，屏幕玻璃、拍摄曝光和完全相同的粒子分布不在一致性承诺内。
