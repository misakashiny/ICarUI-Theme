用户原话：“这里面9个全部做出来”。按九宫格从左到右、从上到下制作。

双击本目录的“打开九款预览.cmd”，或打开 [互动预览](preview.html)。点击缩略图/下拉框切换，支持动态演示、转速/车速滑块、有效零值、无数据以及三个画布比例。预览离线运行，不连接车辆、不写入编辑器草稿或用户主题库。

## 导入与比例

1. 在 ICARUI 左侧打开“主题”→“导入主题”。
2. 选择一个 `.icarzip`，检查后存入主题库，再打开并应用。现有设计请先保存。
3. 默认包为 1672×941；“其他比例”中提供 1920×720、1280×800。预览选择对应比例即可下载。
4. [全部 27 包合集](九款主题_全部比例.zip) 是普通 ZIP，先解压，再导入其中单个 `.icarzip`。

每包已经包含所用素材，可独立复制到其他电脑。JSON 是可编辑源文件；相对素材仍在本目录 `assets/`，跨位置使用优先选择主题包。

三种比例保留构图并居中适配，宽屏和平板边缘可能留空；没有拉伸圆表。不是任意屏幕比例自动重排。

## 数据与编辑

文字、图标、刻度、圆环、进度条、历史曲线和卡片均为可编辑节点。公路/车辆/能量环是独立图片，可替换。参考图的重复或不均匀刻度已按正确量程整理：速度环0～260、转速0～8000，三联水温40～120、油温50～150。

| 显示项目 | 实际绑定 |
|---|---|
| 发动机转速 | `obd.rpm` → `std_0C` |
| 车速 | `obd.speed` → `std_0D` |
| 冷却液温度 | `obd.coolant` → `std_05` |
| 机油温度 | `obd.oil_temp` → `std_5C` |
| 进气温度 | `obd.intake` → `std_0F` |
| 发动机负荷 | `obd.load` → `std_04` |
| 控制模块电压 | `obd.voltage` → `std_42` |
| 瞬时油耗 | `calc.l100` → `calc_l100`，单位 L/100km |

参考读数和演示历史只存在于独立预览，不写入可导入主题。有效0正常显示；缺源数值为 `--`，动态圆弧/进度不假装有值。超量程图形停在端点，数字保留实际值。油耗是否可用取决于APP已有计算所需的真实数据源，不在主题中编造。

第05款使用现有原生历史曲线，等实际历史到达后绘制，缺历史时有等待提示。当前格式的曲线颜色统一跟随主题强调色，本包为青色；卡片边框和图标保留六种颜色。曲线固定量程，不通过自动缩放放大波动。APP的原生曲线可能额外显示小标签，实机字体/排版和性能仍待检查。

## 素材与验证范围

5张装饰素材由内置 imagegen 参照九宫格重建，提示词保存在 [asset-prompts.json](asset-prompts.json)，最终文件位于 `assets/`。未裁切整张参考截图充当可交互主题；字体、车辆、光效细节与原图有差异。能量环为静态装饰，中央速度实时更新。

本轮在隔离浏览器验证实际导入→主题库存入→应用、三种比例、导出回读、素材字节与CRC、零值/缺源和动态历史。用户视觉确认、APP实机与真车数据支持未验。没有新APK、设备操作或车辆请求。详细证据见 [本轮验证记录](../../../../docs/02_验证记录/20261026_ICarUI九款仪表主题.md)。

需要重新生成主题时，运行 `node tools/icarui/themes/04_nine_pack/build-themes.cjs`；生成器只覆盖本目录自身生成产物。合集、实际效果截图在验证后更新。
