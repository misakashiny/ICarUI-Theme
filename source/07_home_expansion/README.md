# ICarOBD 1.21.25 配套主题

冰川 HUD、赤线性能、远征仪表和增强霓虹赛道，每套分别提供 720×1280 竖版与 1280×720 横版，共 8 个可编辑主题包。全部由普通文字、独立数值、形状、分段圆弧、路径进度和已支持的霓虹特效组成，没有把画面做成不可编辑的截图。

## 使用

1. 本地 ICarUI 中打开「主题 → 项目主题」，选择「默认仪表同款」系列，选择横版或竖版。
2. 可调整布局、颜色、数据绑定和量程；预览中的数字只是示例，不会写成固定读数。
3. 通过「导出主题包」保存 `.icarzip`，在 ICarOBD「主题与画布」中导入该文件。建议使用 1.21.25 或更新版本。
4. App 打开主题时按所选横版或竖版方向显示；管理页和主题库仍可自由旋转。相同比例之外的设备会保留完整设计，可能留边。
5. 发布至自己的 GitHub 主题源继续使用编辑器既有发布流程。本次没有上传这些主题，也没有部署编辑器网站。

`ice-*` 为冰川 HUD，`redline-*` 为赤线性能，`expedition-*` 为远征仪表，`neon-*` 为霓虹赛道。每份 `.json` 与 `.icarzip` 对应同一可编辑设计。

## 两端约定

- 设计格式保持 `icar.ui/3`，包格式保持 `icar.pack/1`；以编辑器真实导出的包作为交付。
- 坐标每轴 0～360，叶节点内容在框中心等比绘制，字号和描边使用短轴缩放。生成器按这条既有规则换算尺寸和中心位置；不修改旧主题的坐标含义。
- 绑定采用两端共有别名：`obd.speed`、`obd.rpm`、`obd.coolant`、`obd.voltage`、`obd.fuel_level`、`calc.avg_l100`。平均油耗需要实际计算数据，不伪造缺失值。
- 零值为有效读数；无数据时显示占位并停止进度。连续读数由 App 的既有插值时钟平滑显示，不新增采集订阅。
- 默认仪表是随窗口重排的原生页面；这些配套画布则是可编辑的固定设计比例，不自动改写作者布局。

## 再生成与验证

`make-themes.cjs` 定义可编辑节点；`tests/check-home-expansion.cjs` 在隔离浏览器中检查、导出、重新导入并绘制零值/缺失值/示例值，输出位置由 `ICAR_TEST_OUTPUT_DIR` 显式指定。通过后按已有生成流程登记 `theme-data.js`，运行 `node themes/build-catalog.cjs`，再用 `--check` 检查索引。测试输出不是正式源码；不要覆盖用户的设计或浏览器数据。
