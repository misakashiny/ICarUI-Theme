## 浏览、编辑与保存

1. 打开编辑器左栏“主题 → 项目主题”，按名称、系列或比例筛选。
2. 选择主题后查看详情、尺寸和演示场景。样例值只用于预览，不会成为固定车辆读数。
3. 应用到画布继续修改，或收藏到当前浏览器，也可下载对应尺寸的完整主题包。
4. 自己的 JSON / `.icarzip` 通过“我的收藏 → 导入主题”载入。收藏和项目原件互相独立。
5. 更换浏览器或设备前导出收藏备份。当前编辑器提供“恢复收藏备份”，先预览再恢复；相同内容跳过，同名不同内容可保留副本。

## 维护项目目录

`catalog.js` 保存索引，`_library/` 保存按单款派生的数据；主题详情只加载需要的一款。原始设计、包和预览图保留在各系列目录。编辑器本地直开时也能读取，不要求安装 Node.js。

新增可信项目主题目录时，沿用 `theme-data.js` 的生成格式，登记相应设计、JSON、完整包和预览资源。生成器会执行项目主题数据脚本，因此外来设计应通过编辑器导入，不直接当成项目脚本运行。

在 ICarUI 根目录执行：

```powershell
# 只核对
node themes/build-catalog.cjs --check

# 明确新增主题后，重新生成索引及派生数据
node themes/build-catalog.cjs
```

也可使用 [更新主题库.cmd](更新主题库.cmd)。派生文件不要手动修改；检查需要覆盖索引和单款内容。新增主题还应做真实导入、编辑、导出和重新导入检查，不能只凭索引生成成功判定完成。
