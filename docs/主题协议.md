# 两端共用的主题协议

默认源 `misakashiny/ICarUI-Theme`，固定分支 `theme-library`。`catalog.json` 使用 schema 1；每个比例是一个稳定 `id`，更新使用更高的 `x.y.z` 版本。

字段：`id / version / name / author / description / width / height / pages / minAppCode`。`package` 与 `preview` 分别提供 `path / size / sha256`。所有资源路径均限定为 `themes/<id>/<version>/`，只读取固定 HTTPS GitHub 原始文件地址。

可选 `editor` 字段用于两端归组：`group` 是稳定款式编号，`name` 是款式名称，`series` 是系列，`variant` 是比例键。无该字段的旧目录仍按单款展示。同源同款可选择比例，不同来源保持独立。

完整包包含 `design.json`、引用图片和原有包清单，设计使用 `icar.ui/3`，打包使用 `icar.pack/1`。本次迁移保持所有原包字节与 SHA-256 不变。

目录最大 512 KiB / 500 个版本，包最大 32 MiB，预览最大 2 MiB。编辑器本机导入仍有 16 MiB 文件与 12 MiB 收藏限制，当前所有主题包均低于 3.4 MiB。Android 下载核对大小与 SHA-256，并继续进行路径、解压、素材与设计校验；编辑器同样先核对包摘要，再使用现有导入校验。

发布先上传对象，最后非强制更新分支。更新时保留同款比例分组，不覆盖旧版本；并发冲突由发布器明确返回失败，用户刷新后重试。读目录不需要账号，写入需要目标仓库发布权限。
